ブラウザのモデルキャッシュ

このアプリはサーバーディスクにモデルファイルを保持せず、公式CDN（Google Storage / Hugging Face / jsDelivr）またはステートレスCORS中継から取得したモデル・WASMをお使いのブラウザ（Service Worker + Cache Storage）に直接保存して再利用します。

分類モデル（EfficientNet-Lite0 / Lite2）はブラウザ側 Web Crypto API で SHA-256 とバイト長を検証した上で保存します。不要になったモデルは個別に削除、または一括削除できます。
